# sponsord has moved

sponsord — the deCDN sponsorship daemon and its onramp — is developed in
[decdn/decdn](https://github.com/decdn/decdn) as the `crates/sponsord`,
`crates/sponsord-core`, `crates/sponsord-api`, `crates/sponsord-onramp` and
`crates/sponsord-e2e` workspace members, with this repository's full history.

- Guides: [`docs/sponsord/`](https://github.com/decdn/decdn/tree/main/docs/sponsord)
- Compose and systemd: [`deploy/sponsord/`](https://github.com/decdn/decdn/tree/main/deploy/sponsord)
- Releases: the `sponsord` and `sponsord-onramp` archives and the
  `ghcr.io/decdn/sponsord` / `ghcr.io/decdn/sponsord-onramp` images ship with
  every [decdn release](https://github.com/decdn/decdn/releases) from v0.3.0 on,
  under decdn's `vX.Y.Z` tags and signing keys.
- crates.io: the crate names are unchanged.
- Issues: open ones were transferred to decdn/decdn under the `sponsord` label.

The releases here (up to v0.2.0) stay available for existing pins. This
repository is archived.
